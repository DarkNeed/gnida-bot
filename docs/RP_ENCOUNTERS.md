# РП-встречи

`/встреча гоблин` — один противник. `/встреча гоблин 3` — три гоблина.
`/встреча гоблин 2, шаман` — смешанный отряд. Есть гоблин, громила и шаман; всего от 1 до 3 мобов.
Английский вариант — `/encounter goblin 2, shaman`. Команда работает в группе с включённой ареной.

Создатель — мастер, а не автоматический участник. Он публикует сбор, начинает бой с 1–3 участниками,
отменяет сбор и может досрочно завершить бой. Может вступить сам, если есть место; тогда занимает
обычный слот. Одновременно мастер ведёт не больше одной незавершённой встречи в одном чате.
Мастер без вступления не блокирует своего персонажа для других боёв. Права на управление
проверяются на сервере, а не только скрытием кнопок. Зрители могут смотреть мини-игры.

На сбор — 10 минут, на раунд — 2 минуты; предел — 100 раундов. Каждый игрок выбирает врага нажатием
на его спрайт на арене, затем навык. Выбранный противник подсвечен, имя цели показано одной строкой
над навыками. Отдельной панели кнопок целей нет. Выбор доступен также с клавиатуры; кнопка ⓘ
открывает характеристики отдельно и не меняет цель. Во время мини-игры или после принятия действия
цель менять нельзя. Мастер-наблюдатель целями не управляет.
После действий игроков каждый живой моб выполняет заранее объявленное намерение.
Уровень врагов фиксируется на старте по среднему уровню отряда. У каждого свои HP, эффекты,
контроль и собственный ход. Победа — только после гибели всех мобов. Если выбранную цель уже
добили, действие заменяется защитой без списания энергии: результат проверки попадания не
переносится на другого врага. Атаки врага также не перенаправляются при выбывании объявленной цели.
Навыки игроков сохраняют текущую боевую семантику: направленный удар не становится массовым.

Гоблин — быстрый налётчик, громила каждый третий раунд прикрывает раненого союзника,
шаман каждый третий раунд лечит раненого союзника на 25% максимального HP.
Остальные намерения — физические удары и магический сгусток. Отдельные компактные SVG-спрайты.

Блокирование и уклонение сохраняют настройку персонажа. На каждую объявленную направленную в него
атаку — отдельная мини-игра; её результат привязан к ID врага и не используется против других мобов.
Выключенные мини-игры оставляют обычные случайные проверки. Состав, ход, выбранная цель и
незавершённые мини-игры сохраняются в SQLite и переживают перезапуск.

Никаких наград: XP, франки, трактаты, предметы и ресурсы питомцев не выдаются. Счётчики гарантий
и часовые кулдауны рейд-боссов не меняются. Мастер не может назначить собственные награды.
Встречи используют отдельный тип рейда и не доступны как новый наградной босс в меню рейдов.

Проверка: `.venv/Scripts/python.exe -X utf8 -m unittest discover -s tests -p test_arena_encounters.py`

Демо: `.venv/Scripts/python.exe -X utf8 tools/preview_encounters.py --port 8124`, затем
`http://127.0.0.1:8124/encounter-review`. Одноразовая локальная база, без настоящих токенов и polling;
есть роли мастера/бойца, блок/уклонение, отключённые мини-игры и ширина 390px. Союзники действуют автоматически.
