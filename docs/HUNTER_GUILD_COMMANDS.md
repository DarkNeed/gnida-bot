# Гильдия охотников: команды и сбор отряда

- `/гильдия` или `/охота` — меню гильдии. В ЛС сначала выбери чат.
- `/заказы` — сразу доска заказов, без большого вступительного блока.
- `/охота F1` — создать отряд и опубликовать приглашение в текущем чате.
- `/позвать` — опубликовать приглашение в свой открытый отряд этого чата.

Коды постоянны: буква — ранг F/E/D/C/B/A/S, цифра — тип заказа:
1 — охота, 2 — особый заказ, 3 — подземелье. Например: `/охота C3`.
Код и точная награда указаны на карточке заказа.

## Из мини-приложения

Принять заказ → бесплатное лобби → «Позвать в чат» либо «Начать одному».
Создание через меню само по себе не отправляет сообщение в группу.
Друзья нажимают «Вступить» в карточке Telegram: бот проверяет членство
в чате, ранг, свободного персонажа и завершённый выбор
класса. Обычный персонаж берётся из текущего выбранного слота.

Карточка показывает имена, классы, уровни и количество мест. Из чата
можно вступить и выйти; начать поход и отменить сбор может только лидер.
Начать разрешается одному, максимум — три игрока. Число походов не ограничено.
Первые 3 победы в день дают полную награду на аккаунт. После них: 25% франков,
30% репутации, половина материалов (минимум 1), без трактата и бесплатного припаса.
Дроп экипировки прежний, вещь за финал данжа гарантирована при каждой победе.
В карточке и лобби виден персональный режим наград. Поражение не расходует
полную награду, учитывается день победы; сброс в 00:00 МСК. До старта выйти бесплатно.

После старта вместо кнопок набора появляются «Открыть поход» и, если
уже идёт бой, «Наблюдать бой». В подземелье первая кнопка ведёт к карте,
в обычной охоте и особом заказе — сразу к текущему бою.
Состав и статус обновляются в той же карточке, без новых сообщений каждый ход.

## Ограничение спама

Повторная публикация — раз в пять минут на лидера в конкретном чате,
включая отменённые сборы. Пересоздать отряд для обхода таймера нельзя.
Можно позвать повторно только в открытый неполный отряд. Старая карточка
после перепубликации лишается кнопок набора; ссылка на сам поход остаётся.
Сбор истекает через 30 минут после создания, повторное приглашение его
не продлевает. Кулдаун, сообщение и состояние сохраняются после перезапуска.

## Для обновления BotHost

Новые таблицы SQLite создаются при запуске; ручной SQL не нужен.
Сначала сделай обычную резервную копию папки data, обнови репозиторий
и перезапусти приложение. Новые переменные окружения не требуются.
Боту нужно право отправлять и редактировать свои сообщения в группе.

Локальная проверка без Telegram:

```powershell
$env:PYTHONPATH='tests;.'
.\.venv\Scripts\python.exe -X utf8 -m unittest test_guild test_guild_chat
.\.venv\Scripts\python.exe -X utf8 tools/preview_guild.py --port 8131
```

`/guild-review` — меню, `/guild-chat-demo` — сообщения, отправленные
в локальную имитацию чата. Кнопки Telegram проверяются тестами с mock-ботом.
