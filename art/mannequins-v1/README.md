# Белые манекены — пиксельные эскизы

Нарисованы скриптом в Aseprite, без генератора изображений и без сглаживания.
Варианты: кадры **36 × 36**, **64 × 64**, **128 × 128** пикселей.
Сохранены одинаковые костюмы, белые безликие головы и две позы каждого класса.
64 и 128 отрисованы на своих сетках с дополнительными деталями одежды;
это не увеличенные PNG из папки 36.

Порядок колонок: Оборванец (`ragamuffin`), Милашка (`cutie`), Качок (`jock`), Задрот (`nerd`).

В каждой папке размера:

- `*-idle.png`, `*-attack.png` — отдельные кадры с прозрачностью.
- `*.aseprite` — редактируемый исходник: два кадра и четыре слоя
  (манекен, костюм, детали, эффекты), теги `idle` и `attack`.
- `*-sheet.png` — стойка слева, атака справа, две ячейки без отступов.
- `atlas.png` — четыре класса по колонкам; стойки сверху, атаки снизу.
  Размеры атласов: 144 × 72, 256 × 128, 512 × 256 пикселей соответственно.
- `preview.png` — увеличенный просмотр, не игровая текстура.

`overview.png` сравнивает три размера. Предпросмотры увеличены только целым
множителем без сглаживания; шахматный фон имеется только в предпросмотрах.

Это две ключевые позы, не готовая плавная анимация. Промежуточные кадры ещё
не нарисованы. Производственные спрайты бота не заменены.

Для пересборки **созданных этим скриптом** файлов:

```powershell
& 'C:\MyFiles\Aseprite.v1.3.rc4\aseprite.exe' -b --script-param outdir=C:/MyFiles/Bots/GnidaBot/art/mannequins-v1 --script C:/MyFiles/Bots/GnidaBot/tools/draw_mannequins.lua
```

Скрипт перезаписывает свои выходные файлы. Ручные правки сохраняйте под новыми
именами или в отдельной папке перед повторным запуском.

API: [Aseprite Image](https://www.aseprite.org/api/image),
[Aseprite Sprite](https://www.aseprite.org/api/sprite).
