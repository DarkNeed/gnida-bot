# Доступ к пользовательским командам и переносы строк

## Кулдаун

В карточке команды — «⏳ Кулдаун»: `30с`, `5м`, `1ч 30м` или просто число
секунд. Максимум 7 дней. `0`/`нет` — отключить; у существующих и новых команд
по умолчанию отключён. Ограничение индивидуально для каждого игрока и команды
в её чате. Дополнительные фразы запуска разделяют тот же таймер.
Успешный и неудачный исход запускают кулдаун; недостаток денег, запрет доступа
или отсутствие подходящей цели — нет. Повтор на кулдауне не списывает франки.
Таймер переживает перезапуск; изменение длительности пересчитывает ожидание
от последнего запуска. Проверка доступа, таймера и оплата выполняются атомарно.

В настройке команды «Доступ» можно задать список до 50 пользователей.
Список полностью заменяет предыдущие ограничения. Поддерживаются пробелы,
запятые, точки с запятой и переносы строк:

- `@alice @bob` — только эти двое.
- `-@alice -@bob` — все, кроме этих двоих.
- `@alice @bob -@bob` — только alice; запрет имеет приоритет.
- `123456 -987654` — то же с положительными Telegram ID.
- `нет` — сброс: команда доступна всем участникам чата.

Бот должен знать username по сообщениям в соответствующем чате;
иначе можно указать ID. Правила сохраняются по ID и распространяются на все
фразы запуска команды. У запрещённого пользователя команда не выполняется,
деньги не списываются; её нет и в списке доступных ему команд.
Старый доступ одному пользователю продолжает работать до изменения настройки.

При добавлении/редактировании варианта ответа в меню одно сообщение — один
вариант, любые переносы и пустые строки внутри сохраняются. Лимит — 1000 символов
на вариант, включая переносы, до 20 вариантов каждого исхода.

При создании команды старый формат «каждая строка — отдельный вариант» сохранён.
Для многострочных вариантов используется отдельная строка `---`:

```text
{actor} пошёл к {target}.
Но всё оказалось не так просто.
---
Второй вариант.

Ещё один абзац второго варианта.
---
```

Для единственного многострочного варианта тоже нужна завершающая строка `---`.
В меню добавления одного ответа разделитель не нужен.
