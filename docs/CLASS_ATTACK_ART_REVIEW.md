# Оформление атак классов — локальная проверка

Галерея: `http://127.0.0.1:8130/qte-lab/art/`

Запуск из корня проекта (без токена, базы и Telegram):

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/preview_qte_art.py --port 8130
```

В галерее — автоматическая демонстрация. Для самостоятельной игры служат ссылки
«Попробовать»: уклонение/попадание в атласе и отдельная лаборатория блокирования.
Можно выбрать класс, любой из его вариантов навыков, остановить воспроизведение
или выбрать точный кадр на 2–6 секунде. На телефонах карточки идут в один столбец.

## Что изменено

Один слой `webapp/qte-art.js` используется боевой ареной, наблюдателями и обеими
лабораториями. Галерея показывает те же отрисовщики, не отдельные макеты.

| Класс | Визуальный почерк |
| --- | --- |
| Оборванец | Кулаки, пыль и ржавый зубчатый клинок |
| Милашка | Сердца, поцелуи, лапки и тройные кошачьи рассечения |
| Качок | Кулаки, ракеты и вагоны паровозика |
| Задрот | Терминалы, пакеты кода, скобки и полосы исполняемого кода |
| Большой палец | Латунные пули со стальным наконечником и штыки |
| Указательный палец | Бумажные предписания с красной печатью; текст Указа вместо COMPILE |
| Средний палец | Кулаки, металлические цепи, тяжёлые удары по земле |
| Кольцо | Капли, лужи краски, мазки и нарисованные когти |
| Звёздный клинок | Холодная сталь, звёздные лезвия, небесные разрезы |
| Воин | Стальные и кровавые клинки, щиты, языки огня Феникса |
| Маг | Кристаллы маны, души, кости, огонь, лёд, молнии, чёрные провалы |
| Жрец | Священные кресты, молоты, глефы и световые руны |
| Охотник | Серебряные пули, пилящие лезвия, когти и лунные серпы |
| Лудоман | Сохранено существующее отдельное оформление казино |

Оформление различается по классу и тематике навыка/ветки. Это не новые
индивидуальные траектории для каждого навыка: исходные узоры, их сложность,
урон, тайминги, критические зоны и радиусы столкновений сохранены.
Шлейфы декоративные. Зоны ударов и опасные полосы по-прежнему заполнены,
а золотые отметки направления блока и розовые критические зоны не перекрашены.
Специальные отрисовщики Назарика, Капеллана, Кита и казино не заменяются.

## Проверки

```powershell
$env:PYTHONPATH='tests;.'
.\.venv\Scripts\python.exe -X utf8 -m unittest test_qte_art test_qte_patterns test_qte_block_live test_qte_watch test_nazarick test_arena_chaplain
```

Тесты отрисовки проходят по всем 279 профилям каталога, в том числе боссовым,
на разных фазах предупреждения/активности, для уклонения, блока и попадания.
Проверяются числовые аргументы Canvas, баланс save/restore и неизменность
состояния боя. Отдельно сравниваются результаты симуляций с отрисовкой и без.

Публикации в GitHub в рамках этой задачи нет.
