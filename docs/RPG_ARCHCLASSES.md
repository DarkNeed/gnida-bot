# Классические RPG-архиклассы

Внедрены 15 октября 2026. Девять веток с отдельными стандартными обликами
на 10 и 20 уровнях; лимиты памяти и боевого набора не расширены.

| Класс | 10 уровень | 20 уровень |
| --- | --- | --- |
| Воин | Берсерк | Феникс |
| Воин | Рыцарь | Страж |
| Маг | Некромант | Повелитель смерти |
| Маг | Элементалист | Повелитель стихий |
| Маг | Архимаг | Пустотный маг |
| Жрец | Епископ | Архиепископ Рассвета |
| Жрец | Паладин | Инквизитор |
| Охотник | Охотник звериной крови | Первородный зверь |
| Охотник | Охотник бледной луны | Белая луна |

Выбор финальной ступени явный: «Развить» либо «Остаться». Он сохраняется
между перезапусками и не сбрасывает опыт. Для уже достигших 20 уровня RPG-бойцов
появляется тот же выбор. Собственные PNG сохраняются, стандартный облик меняется
только без пользовательской картинки. Состояние начатых боёв не переводится
на новую ступень принудительно.

## Развитие и бой

- 12: особенности родного цикла (Натиск по расколу, раскол от контратаки,
  защита скелетом, стихийные реакции, экономия Эха, очищение молитвой,
  защита союзника, ускоренное Зверство, Лунная метка).
- 15: уже существующие фирменные навыки получают связанный с веткой цикл.
- 18: улучшение фирменных атак и подготовки (сохранение части Натиска,
  усиленный контрудар, продление призыва, возврат маны за три стихии,
  шаг новой цепочки Эха, молитва/пробитие, частичный расход Воздаяния,
  возврат Зверства, сохранение окна при промахе).
- 20: отдельный финал на кнопке прежнего навыка, не пятый боевой слот.

Феникс накапливает до 5 Жара и при подготовке получает трёхчастный огненный
Натиск за 50 энергии. Один раз за бой встаёт с 30% HP от смертельного вражеского
урона при 3 Жара. Высокий Жар повышает риск и берёт 5% максимального HP за родную
атаку, не опуская HP ниже 1.

Страж при 3 Стойкости получает Бастион за 50 энергии: 50% пробития и защита
себя и раненого союзника. Повелитель смерти за 3 Души и 50 маны вызывает
Стража и Палача на три действия; новые слуги заменяют старых.

Повелитель стихий завершает три метки Катаклизмом за 50 маны с тремя
проверками попадания. Пустотный маг с Эхом после четырёх собственных действий
использует Точку небытия за 70 маны: сила 48, пробитие 60%, один успешный удар
за бой. Горизонт событий поглощает до 10 действительно потраченной энергии;
в рейде её получает именно создавший эффект маг, один раз за действие босса.

Архиепископ с 3 Веры получает молитву за 60 маны один раз за бой: одно
воскрешение на весь отряд, либо лечение живых. Вышедшие и лишённые награды
участники не возвращаются. Инквизитор с 3 Веры/Воздаяния получает двухчастный
Приговор за 60 маны с 50% пробития и защитной печатью.

Первородный зверь при 3 Зверства получает разовое окно Ярости за 50 энергии
на три собственных действия, затем усиленные серии когтей. Белая луна в окне
прерывания с Лунной меткой получает разовую двухчастную атаку за 60 энергии,
пробитие 60%. Разовые атакующие финалы фиксируются при хотя бы одном попадании;
полный промах сохраняет подготовку, но не возвращает потраченную энергию.

Все заряды, окна и разовые флаги сериализуются в боевое состояние. Серия имеет
отдельные промахи/уклонения, но платит один раз и расходует подготовку один раз.

## Рисунки

18 готовых прозрачных PNG: `webapp/assets/archclasses/*` для девяти RPG-веток
и их файлов `_final.png`. Ширина 512, высота до 768; поля по 24 пикселя.
Пустая высота вокруг широких фигур не сохраняется, пропорции рисунков сохранены.

Источники — локальные утверждённые листы `output/rpg-archclasses-review-v2/`
(маги и охотники) и `output/rpg-archclasses-review-v3/` (воины, жрецы,
некроманты). Они не перерисованы, вырезка программная с разрешения пользователя.
Исходные листы не нужны серверу: в Git включены готовые игровые PNG.

Для повторного локального экспорта из этих листов:

```powershell
.venv/Scripts/python.exe -m pip install numpy opencv-python-headless
.venv/Scripts/python.exe -X utf8 tools/prepare_rpg_archclass_sprites.py
```

Повторный экспорт существующих файлов требует явного `--overwrite`.
OpenCV/numpy нужны только офлайн-инструменту, не запускающемуся на сервере.

## Проверка и выпуск

```powershell
.venv/Scripts/python.exe -X utf8 -m unittest discover -s tests
```

Для визуальной проверки без Telegram и без базы пользователей:

```powershell
.venv/Scripts/python.exe -X utf8 tools/preview_arena.py --port 8102
```

Открыть `http://127.0.0.1:8102/?demo=1&fighter=hunter&arch=hunter_moon`.
Параметр `stage=10` показывает прежнюю ступень; по умолчанию 20.

После обновления кода на хостинге перезапустить сервис обычным способом.
Новых переменных окружения и новых зависимостей бота нет. Данные игроков
не сбрасываются; новая таблица для этих механик не требуется.
