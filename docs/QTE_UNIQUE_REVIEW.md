# Атлас атак — отдельный полигон для согласования

Адрес: `/qte-lab/unique/`. Сам полигон не читает аккаунты и не меняет
настоящие бои. После утверждения его движок подключён к обычным боям
с независимой серверной проверкой (`arena_qte_patterns.py`). Старый полигон
`/qte-lab/` сохранён для сравнения, а его движок — для незавершённых старых этапов.

## Проверка

1. Выбрать навык через быстрые примеры, фильтр класса или поиск.
2. Сначала пройти «Уклонение» на равных характеристиках, затем «Слабее врага».
   Перед узором есть отдельный отсчёт 1 с; за это время маркер не двигается,
   снаряды не появляются и HP не снимаются. После отсчёта остаются все 6,8 с атаки.
3. Попробовать «Попадание»: шкала, дуга, кольцо, пульсация и прицел имеют
   одинаковый принцип — белая метка должна совпасть с золотой областью.
   Перед серией есть 1 секунда подготовки, перед каждым ударом — сигнал 0,25 с.
   Метка проходит цель туда и обратно; разрешено до двух нажатий на удар.
   Первый промах оставляет вторую попытку. Между нажатиями 0,22 с, удерживание
   пробела и спам в подготовке не расходуют попытки. Успех нельзя продублировать.
4. Менять номер узора для другой раскладки; сохранять номер для повторения.
5. После попытки выбрать оценку. Журнал содержит навык, режим, номер узора,
   четыре характеристики, опорный урон, тестовые HP, число касаний по категориям
   силы и результат. Оценки живут только в памяти вкладки:
   их можно скопировать или прислать скриншот, они не отправляются автору автоматически.

## Что реализовано

27 семейств: рубящие дуги, выпады, удары/волны, захваты, стрельба, ракеты,
паровозик, обаяние, взлом, патчи, предписания, краска, зверь, созвездия,
чистая мана, свет, пустота, души, огонь, лёд, молния, депортация,
отражения, монеты, затмение и пыль.

Каталог собирается из встроенных навыков, условных усилений, архиклассов,
финальных и мастерских форм и навыков боссов. Количество показано в интерфейсе.
Именованные формы отличаются параметрами, ритмом, направлением и иногда
геометрией внутри семейства. Это **не сотни независимых игровых движков**:
связанные приёмы разделяют механику. Администраторские навыки из живой базы
сюда не загружаются — полигон вообще не обращается к базе.

В уклонении каждый отдельный снаряд или область имеют собственную силу и наносят
урон сразу при касании: уменьшается тестовая полоска HP, над маркером появляется
число. Длительное нахождение в одной области или повторное касание одного снаряда
не ранят снова. Разные снаряды одного исходного удара ранят независимо. Соединённые
сегменты одного разряда молнии считаются одним физическим разрядом.

При опорном значении 40 типовые значения: мелкий — 4, обычный — 12, тяжёлый — 24,
финальный — 40. Это **не распределение общего бюджета**: суммарный урон серии
может превышать 40. У паровозика ключевые вагоны усиливаются к финалу
(10/14/18/24/26/40 при опоре 40), а мелкие вагоны наносят по 4. У тигробоя
основные разрезы наносят 24, финальный — 40, лёгкие догоняющие — 6.
Более сильные угрозы выделяются золотым/светлым цветом и свечением; уже
задевшие маркер тускнеют. В режиме попадания успешный исходный удар получает
свою весовую категорию; дополнительные попытки не добавляют лишних ударов.

Опорный урон и запас HP настраиваются отдельно от точности и уклонения.
Пока это демонстрация ощущения урона, не окончательные значения классов.
На полигоне ничего не расходуется. Правила обычных боёв описаны в
`COMBAT_MINIGAMES.md`; их результат рассчитывается отдельно на сервере.

## Техническая граница

- `arena_qte_unique.py`: каталог и read-only HTML/JS-маршруты, без аккаунтов.
- `webapp/qte-unique/engine`: отдельная чистая симуляция, шаг 120 Гц,
  предупреждение фиксирует цель; движущиеся снаряды и пути игрока проверяются
  на пересечение между кадрами, а не только в конечной точке.
- `client`: только локальные ввод, отрисовка, журнал и пауза.
- Live-виджет использует тот же JS-движок через `/static/qte-engine.js`;
  Python-порт независимо проверяет нажатия, движения и вес каждого касания.
  Полигон по-прежнему не отправляет никаких результатов в API боёв.
- Тестовый поиск безопасной траектории содержится только в `tests/`,
  не загружается в браузер и не является автоматическим уклонением игрока.

## Тесты

```powershell
$env:PYTHONPATH='tests'
.\.venv\Scripts\python.exe -X utf8 -m unittest test_qte_unique test_qte_lab test_arena_assets test_qte_live
```

Визуальная проверка на отдельном локальном сервере:

```powershell
.\.venv\Scripts\python.exe -X utf8 tools/preview_arena.py --port 8107
$env:PLAYWRIGHT_CHANNEL='msedge'
node tests/qte_unique_browser.cjs
```

Playwright должен быть доступен Node через установленный пакет или `NODE_PATH`.
