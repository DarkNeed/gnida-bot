# Питомцы и анимация гачи — визуальное демо для утверждения

Это архив первоначального визуального утверждения. Игровая версия уже подключена:
см. `PETS.md` в корне проекта. Production-спрайты лежат в `webapp/assets/pets/`.
Исходные изображения и вспомогательное демо сохраняются локально; для запуска
бота они не нужны. Часть больших исходников не включена в Git.

16 отдельных рисунков созданы встроенным image_gen, по одному вызову на спрайт.
Итоговый набор промптов: `PROMPTS.json`. Пути исходных результатов генератора:
`SOURCES.json`. Оригинальные PNG в этой папке не менялись.

С разрешения пользователя выполнена программная обработка только прозрачности:
удалены низкоальфовые ореолы за пределами силуэта и скрытые RGB-фоны. Экспорты
в `clean/` — 768×768 RGBA с одинаковыми полями, без перерисовки персонажей.
Скрипт: `tools/prepare_pet_sprites.py`; параметры и размеры экспорта: `EXPORT.json`.
Сводный лист: `contact-sheet.jpg`.

Рисованная мрачная аниме-стилистика, целые персонажи, не пиксельные и не эмодзи.
Отсылки к персонажам и мемам — визуальные кандидаты, а не проверенные лицензии
на коммерческое распространение. При отдельной публикации игры нужно вернуться
к проверке прав на узнаваемые образы.

## Посмотреть демо

```powershell
.venv/Scripts/python.exe -X utf8 tools/preview_pet_gacha.py --port 8100
```

Открыть `http://127.0.0.1:8100/`. Сервер слушает только localhost и отдаёт только
демо и перечисленные спрайты; нет доступа к произвольным файлам проекта.
Не запускает polling Telegram, не читает токены и не подключается к базе.

Сцена: посылка → встряска → заряд печати цветом редкости → открытие крышки и
частицы → раскрытие питомца → карточка результата. Полное открытие занимает
около 3,7 секунды после загрузки картинки. Есть пропуск, Escape, мягкий режим,
отключение синтезированных звуков, просмотр на светлом фоне, мобильная
и десктопная компоновка. При уходе со страницы эффекты останавливаются.
Нет внешних шрифтов, изображений или аудиофайлов.

Редкости в галерее назначены **только для демонстрации цветов**. Случайный режим
равномерно выбирает из 16 рисунков, не моделируя будущие вероятности гачи.
Можно принудительно выбрать любого питомца и любой цвет раскрытия. Питомцы
показывают концепцию универсальной пользы; боевые способности пока не реализованы.

Это не действующая гача: нет списания франков/Stars, покупки билетов, гарантий,
дубликатов, инвентаря, прокачки или выдачи питомца. Не подключено к рабочей арене.
После утверждения рисунков и сцены можно внедрять экономику и боевые механики.
