# Очередь каста и совместная защита

## Область внедрения

Новые встречи с независимыми мобами (`create_encounter`), включая бои гильдии,
защиты владений и этажи нового Назарика, получают `action_queue_version=1`.
Сценарные рейды (Лей Хенг, Фуфелшмерц, Кит, Капеллан, Китобой, первоначальный
поход Назарика) также используют эту очередь через `arena_boss_queue`. Их родные
обработчики исполняют отдельные действия, сохраняя фазы, призывы и реакции.
Сохранённый старый раунд завершает старые открытые QTE и переходит на очередь
со следующего раунда. Одиночная арена и PvP сохраняют своё управление.

Намерения — только линии на арене, без отдельной панели. Название атаки и число
целей доступны в подсказке линии. На одиночной линии к союзнику есть щит
перехвата. Навык сразу отправляется по нажатию; подтверждения «Сделать ход» нет.

## Исполнение

После атакующих проверок и выбора действий живым отрядом сервер строит очередь.
База каста: защита 1,6 с, поддержка 2,4 с, атака 3 с, тяжёлая атака (сила от 35
или шесть ударов) 4,2 с. Формула: `1,25 + база / (1 + скорость * 0,018)`,
с округлением до четверти секунды. Скорость не даёт дополнительных действий
и не ускоряет снаряды. Клиент не задаёт времена, состав очереди или цели врагов.

Гибель/оглушение до выпуска отменяет действие. В независимых встречах сначала
выпускаются все живые враги группы; совпадающая атака игрока не отменяет уже
выпущенное намерение. В сценарных рейдах при точном равенстве сначала разрешаются
игроки, затем проверяются фазовые барьеры и выпускается группа врагов. После
выпуска группа защищается в одном окне на каждого
получателя. Последующие касты продолжаются после расчёта группы; стенное время
мини-игры не меняет инициативу.

Рейд больше не делится на «весь отряд, затем босс». Родные действия босса и его
призывов планируются вместе с игроками. Позднее оглушение переносится на следующий
каст босса, Кара болот остаётся отдельной реакцией. Визуальный повтор группирует
события по раунду и `cast_at` и запускает их анимации одновременно; переходы фаз
и перемотки остаются отдельными границами. Дубликаты HUD исходных мини-игр скрыты,
подсказки механик сохранены.

Поля разных игроков разделены. Повторы получателей удаляются. Массовый навык
платится, получает кулдаун и тикает один раз; урон считается отдельно по целям.

Перехват: одна одиночная атака на бойца за раунд, 8 энергии, резерв до выбора
навыка. Отмена до выбора бесплатна. Проверяется суммарная доступность энергии
для навыка и реакции. Массовую атаку перехватить нельзя. Перехват недоступен
после начала очереди или подтверждения действия прикрываемым игроком.

## Проверка ввода и сохранение

Версия QTE 4 содержит серверный список исходных защитных дескрипторов. Рисунки
атак не заменяются. Уклонение получает общее движение; блок — один щит/стойкость,
без умножения поворота или восстановления на число врагов. Одна запись ввода
проигрывается сервером на 120 Гц, результаты разделяются по источникам.
Пропуск/таймаут засчитывает угрозы каждого источника, не успешную защиту.

Очередь, выпущенные снимки и результаты сохраняются в JSON боя. Повторный
challenge не исполняет действие второй раз. Публичный API не выдаёт внутренние
снимки и чужие результаты. Наблюдение поддерживает версию 4 без хранения повторов.

- `python -m unittest discover -s tests -p test_boss_action_queue.py`
- `node tests/raid_timeline.cjs`, `node tests/qte_combined_view.cjs`.
- `python -m unittest discover -s tests -p test_arena_encounters.py` — старый формат.
- `python -m unittest discover -s tests -p test_nazarick_dungeon.py`
- `python -m unittest discover -s tests -p test_qte_watch.py`
- `node tests/qte_watch.cjs`, `node tests/qte_watch_follow.cjs`.

Настоящие UI/API на временной SQLite: `tools/preview_party_queue.py --port 8142`.
Путь `/party-queue-review`, параметры `scenario=cover|sweep`, `defense=block`.
Сценарные боссы: `tools/preview_boss_queue.py --port 8143`, `/boss-queue-review`.
По умолчанию Аинз с двумя призывами, `boss=chaplain|kit|whaler|lei_heng|doofenshmirtz`
выбирает другого босса. `defense=block` переключает защиту на блок.
Только loopback и синтетическая авторизация. Настоящие аккаунты/бот не подключены.
Предыдущий автономный демонстратор остаётся на порту 8141.
