# Капеллан — четыре редакции (локальное согласование)

Рейд без ограничения по уровню входа (рекомендуется 20+), фиксированный уровень босса 25, 1–3 участника.
Публичный сбор: `/рейд капеллан` (также `/raid chaplain`); тихий рейд — через меню рейдов.
Одинаковое максимальное HP во всех четырёх фазах: 720 / 1080 / 1440.

## Жизненный цикл

На 30% HP в фазах 1–3 босс полностью восстанавливает ТОЛЬКО собственное HP и переходит дальше. Игроки, их HP, ресурс, статусы, кулдауны и павшие товарищи этим восстановлением не меняются. Переход заменяет действие босса на границе его действия, чтобы не исполнить новую, ещё не объявленную атаку с чужой записью QTE. Смертельный удар не пропускает фазы. В четвёртой фазе восстановления больше нет, смерть завершает бой и только тогда выдаются награды.

Получаемый боссом урон: ×1,6 / ×1,3 / ×1,1 / ×1. Первая и вторая фазы имеют строго одинаковые спрайт и фон; счётчик фазы до третьей скрыт. Третья — трещины/разошедшаяся мантия, четвёртая — раскрытая нечеловеческая фигура. Максимальное HP не меняется.

## Обычный откат

Самостоятельное объявленное действие вместо атаки раз в 5–7 реальных раундов. Возвращает combat snapshot начала предыдущего раунда в пределах текущей фазы: HP, ресурс, снимаемые эффекты, обычные кулдауны, призывы и связанные боевые счётчики. Не переносит назад саму фазу, её восстановления, следующий срок отката, реальные раунды, AFK/ручные действия, выход участника, награды, расход предметов и уже использованные одноразовые способности. Активный трактат «Последняя поправка» сохраняет оставшееся окно применения, а потраченный не возвращается.

Откат не расходует три фазовых восстановления. Ошеломление может сорвать действие отката; он остаётся просроченным намерением до следующей возможности исполнить его. Поражение всего отряда не отменяется автоматически.

«Закрепить мгновение» тратит действие и действует три раунда. Сохраняет выбранный результат при обычном откате: урон боссу, фактическое лечение отряда либо очищение. Несколько участников могут сохранить разные типы результата. Закрепление НЕ отменяет фазовые восстановления.

## Атаки и QTE

Фаза 1: прежние Часовая стрелка / Колокол исправления / Последняя редакция, без облегчения.

Фаза 2:
- Принудительная синхронизация — две вращающиеся стрелки, исходящие из центра циферблата. Пунктир заранее показывает начало и конец прохода; сервер проверяет столкновение с движущейся стрелкой.
- Недостаточно прав — опасные области в виде окон системы.
- Исправление позиции — удар по недавнему следу игрока и отложенный луч.

Фаза 3:
- Остановить процесс — световые снаряды временно останавливаются и продолжают путь.
- Откат координат — заранее показанное возвращение маркера в прежнюю позицию, затем атака.
- Удалить выделенное — системное выделение с отложенным световым пересечением.

Фаза 4:
- Протокол вечности — остановка световых снарядов плюс отложенная вращающаяся стрелка.
- Да будет свет — четыре разнесённые вспышки, проход шириной 120–136px вместо 96px, предупреждение минимум 0,65с; дополнительный тонкий луч только на каждой второй волне с задержкой 0,58с.
- Полный доступ — выделение и два отложенных пересечения.

Циферблат: золотые атакующие стрелки вращаются вокруг его центра, пунктир показывает границы прохода, столкновения считаются по той же геометрии на сервере. В остальных фазовых паттернах голубые стрелки показывают отсчёт до следующего реального удара; сами голубые стрелки не наносят урон. Боевые паттерны первой фазы не изменены.

Подготовка перед QTE сохраняется. Точность/уклонение продолжают определять сложность. У блокирования с фазами растёт число направленных угроз, немного уменьшается подготовка. Все физические контакты/возвраты координат проверяются на сервере, клиент присылает только управление. Управление игрока при остановке снарядов не отключается. Первая фаза не затронута фазовыми множителями сложности.

## Вмешательства в интерфейс

- Каждая попытка открыть характеристики босса — золотой разрез и автоматическое закрытие через 450 мс. Настоящие характеристики вообще не вставляются в карточку, в том числе для скринридеров. Повторное открытие не обходит запрет. Характеристики союзников и остальных боссов доступны как обычно; без урона и блокирования настоящего выхода.
- Со второй фазы — стабильная на раунд перестановка кнопок (ID навыков и реальные loadout не меняются).
- Повреждённые названия: стоимость/кулдаун видны; удерживание 420 мс открывает нормальную карточку и НЕ применяет навык. Для клавиатуры и скринридера имена остаются доступны.
- С третьей фазы — визуальная подмена спрайтов с одним участником. Имена, HP, цели и управляющие игроки не меняются.
- Игровые SYSTEM-уведомления не подменяют реальные ошибки приложения.
- Предпочтение reduced-motion учитывается. Нет полноэкранного стробоскопа.

## Проверка

Запуск:
`.venv/Scripts/python.exe -X utf8 tools/preview_chaplain.py --port 8123`

Открыть http://127.0.0.1:8123/chaplain-review. Только временная SQLite и синтетическая локальная авторизация; без production-базы, настоящего токена и polling.

Сверху: четыре фазы, порог 30%, обычный откат, финальное добивание, трактат, отдельный выбор каждой атаки каждой фазы, партия 1/3 и ширина 390px. Нажать «Защищаться» для входящей мини-игры; ⓘ босса — для разреза. Каждый сценарий начинает новый временный бой.
