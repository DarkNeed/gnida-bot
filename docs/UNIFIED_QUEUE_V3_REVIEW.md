# Единая очередь v3 — локальная проверка

Запуск: `.venv\Scripts\python.exe -m tools.preview_unified_queue --port 8154`.
Открыть: http://127.0.0.1:8154/unified-queue-review

Обновлённая проверка в настоящем интерфейсе арены:
http://127.0.0.1:8154/arena-queue-review

Она напрямую вызывает battleScreen/raidScreen из рабочего battle-client,
использует те же спрайты, HUD, карточки навыков, окна характеристик/эффектов,
анимации и QTE. Классовые HP и скорость не повышаются; четыре слота навыков.
Настройки сценария доступны через шестерёнку, отдельной верхней формы нет.
Единственная ветка в основном клиенте ограничена loopback + точным путём
arena-queue-review. Polling отключён только для неё; live API не вызывается.
Старая пользовательская ссылка unified-queue-review перенаправляет на этот
экран; прежний технический полигон оставлен отдельно по /queue-lab.

Новые правила изолированы от работающих боёв. Нет Telegram, базы, наград,
публикации или постоянных повторов. Сессии хранятся только в памяти процесса.

## Модель

- При выборе действие ставится в очередь на `now + duration` и резервирует энергию.
- Эффекты и урон применяются при завершении, после существующей QTE-проверки.
- Пока игрок выбирает или проходит QTE, боевое время не идёт.
- Сначала завершается самый ранний каст; совпавшие времена образуют одну группу.
- Одинаковые времена входящих атак по одному герою используют существующий
  комбинированный блок/уклонение, без переписывания рисунков мини-игр.
- После завершения каста герой снова выбирает действие. Автоповтора нет.
- Если враг успевает до конца длинного каста, сначала разрешается его атака,
  после чего подготовка героя продолжается. Гибель отменяет незавершённый каст.
- Скорость считывается в момент выбора и не двигает уже зафиксированное намерение.
- В командном сценарии каждый готовый герой получает свой выбор. Все используют
  одну шкалу, а не отдельные раундовые часы.
- Начало следующего собственного действия использует существующий реген ресурса.

## Длительности

`arena_skill_timing.py` задаёт длительность любому активному навыку, включая
пользовательские навыки по тем же правилам. `cast_base` имеет приоритет.
Остальным базовое время даётся по типу действия, силе, цене, меткам быстрых и
многоударных атак. Все 305 текущих навыков классов, трактатов, рейдов, гильдии и
Назарика включены в раскрываемый каталог. Наличие времени не переносит сценарий
целого босса в этот полигон.

Итог: `max(0.75, округление_до_0.05(base / (1 + speed * 0.035)))`.

Прогноз сравнивает завершение выбранного навыка с ближайшим входящим кастом
именно по выбранному герою: до / одновременно / после. Равенство не считается
безопасным окном. Шкала не меняет масштаб от наведения; мобильная кнопка ⓘ
показывает тот же прогноз.

## Проверять

1. Ассасин: надрез, затем укол — два разных действия до первого залпа.
2. Медленный класс: длинный навык — входящий удар разрешится раньше.
3. Синхронный залп: несколько коротких действий, затем общая защита от двух врагов.
4. Два героя: выбери каждому свой навык; после быстрого каста снова выбери действие
   только быстрому герою, пока союзник продолжает подготовку.
5. Убей бомжа раньше окончания каста: его будущая помеха исчезнет.
6. Смена класса, ветки и режима защиты не меняет текущую сессию до «Нового боя».

## Ограничения демо

- HP и скорость теперь соответствуют классовым формулам; отдельно изменяется
  только расчёт очереди и длительностей. Это не финальный ребаланс классов.
- Все герои управляются одним тестировщиком; нет сетевого ожидания других игроков.
- Нет фаз боссов, наград и перехвата в этом новом тестовом интерфейсе.
- Индивидуальный тюнинг длительностей остальных классов выполняется после проверки
  модели; пока они получают полноценные, но вычисленные по правилам значения.
- Автоповторы старого раундового движка не меняются до отдельного утверждения
  переноса новой модели в основные бои.
